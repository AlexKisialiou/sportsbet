# Changelog — Mamkiny Gamers United

## v1.6 (2026-06-18)
### Новое
- **APScheduler** (`app/scheduler.py`) — периодическое автообновление матчей UCL/PL/WC; интервал и вкл/выкл хранятся в таблице `Setting`; перезапускается без рестарта сервера
- **Форма команд** — тултип с последними N матчами команды (результат, счёт, соперник, Д/Г); на десктопе по наведению, на мобильном по тапу
- **Комментарии к матчам** — модель `MatchComment`; каждый пользователь может оставить один комментарий на завершённый матч
- **Страница статистики** (`GET /stats`, только для админов) — аналитика предсказаний по лигам
- **Модель `ReleaseNote`** — заготовка для отображения changelog в интерфейсе

### Суперадмин
- Новый блок «Автообновление»: включить/выключить + интервал (5–120 мин)
- Новый блок «Форма команд»: количество матчей в тултипе (0 = все)
- Новый блок «Комментарии»: максимальная длина (1–500 символов)

### API
- `POST /api/settings/auto-fetch` — включить/выключить автообновление, задать интервал
- `POST /api/settings/team-form-count` — количество матчей в форме
- `POST /api/settings/comment-max-length` — макс. длина комментария
- `GET /api/team/<id>/recent-matches?league=UCL` — последние матчи команды
- `POST /api/match/<id>/comment` — создать/обновить комментарий
- `DELETE /api/match/<id>/comment` — удалить комментарий

### tg_notify
- Обновлён `notify.py`: улучшена логика уведомлений
- Добавлены переменные окружения в `.env.example`
