# Changelog — Mamkiny Gamers United

## v1.8 (2026-07-08)
### Улучшения
- **Авто-переход к следующему игровому дню** — если настроено несколько игровых дней заранее, второй день появляется в разделе ставок сразу после завершения первого, независимо от даты матчей; раньше второй день показывался только в день своих матчей

## v1.7 (2026-07-01)
### Новое
- **Игровые дни (`featured_round`)** — при назначении матчей в «для ставок» каждому матчу присваивается номер игрового дня; таблица прогнозов группирует матчи по дням и сортирует корректно
- **Архив (день 0)** — все завершённые матчи без игрового дня переносятся в специальный раунд 0 («Архив»); кнопка «→ день 0» в суперадмине на строке каждой лиги; архив не считается в лимит `pred_days`
- **Учёт доп. времени** — поля `win_type` (`aet`/`pen`), `penalties_home`, `penalties_away` в модели `Score`; отображается «(д.в.)» и «(пен. X:Y)» в карточках матчей и таблице статистики
- **Telegram-напоминания** — APScheduler job `_auto_tg_remind_job`: за N минут до первого матча игрового дня отправляет список незаполненных прогнозов; тихие часы настраиваются
- **Переключатель API ставок** (`odds_fetch_enabled`) — суперадмин может выключить запросы к The Odds API чтобы сэкономить квоту (500 req/мес)

### Суперадмин
- **✈️ Telegram-напоминание**: включить/выключить автоотправку, задать «за N минут», тихие часы (от/до), ручная отправка «Отправить сейчас»
- **→ день 0**: кнопка на строке каждой лиги — переносит все завершённые матчи без `featured_round` в архив (день 0)
- **📡 Запросы к API ставок**: toggle `odds_fetch_enabled`

### API
- `POST /api/admin/fix-round0` — перенести матчи без игрового дня в `featured_round=0` для указанной лиги (superuser)
- `POST /api/settings/tg-remind` — настройки Telegram-напоминаний (enabled, before_min, quiet_from, quiet_to)
- `POST /api/admin/tg-remind` — ручная отправка Telegram-напоминания

### Статистика
- «Прогнозы по матчам» перенесена в самый низ страницы статистики
- Нумерация игровых дней (`Игровой день N`) не сдвигается из-за архивных матчей (день 0)
- Архивный блок отображается в конце таблицы с подписью «Архив»

### Исправления
- Таблица прошедших матчей: сортировка по `featured_round desc, kickoff_time desc` — разделители игровых дней больше не прыгают
- Статистика: графики начинаются с нуля (точка «Старт»)
- Мобильный вид страницы статистики: горизонтальный скролл, скрыты колонки точности на узких экранах

## v1.6 (2026-06-18)
### Новое
- **APScheduler** (`app/scheduler.py`) — периодическое автообновление матчей UCL/PL/WC; интервал и вкл/выкл хранятся в таблице `Setting`; перезапускается без рестарта сервера
- **Форма команд** — тултип с последними N матчами команды (результат, счёт, соперник, Д/Г); на десктопе по наведению, на мобильном по тапу
- **Комментарии к матчам** — модель `MatchComment`; каждый пользователь может оставить один комментарий на завершённый матч
- **Страница статистики** (`GET /stats`, только для админов) — аналитика предсказаний по лигам
- **Модель `ReleaseNote`** — заготовка для отображения changelog в интерфейсе

### Суперадмин
- Новый блок «Автообновление»: включить/выключить + интервал (5–120 мин)
- Новый блок «Форма команд»: количество матчей в тултипе (0 = все)
- Новый блок «Комментарии»: максимальная длина (1–500 символов)

### API
- `POST /api/settings/auto-fetch` — включить/выключить автообновление, задать интервал
- `POST /api/settings/team-form-count` — количество матчей в форме
- `POST /api/settings/comment-max-length` — макс. длина комментария
- `GET /api/team/<id>/recent-matches?league=UCL` — последние матчи команды
- `POST /api/match/<id>/comment` — создать/обновить комментарий
- `DELETE /api/match/<id>/comment` — удалить комментарий

### tg_notify
- Обновлён `notify.py`: улучшена логика уведомлений
- Добавлены переменные окружения в `.env.example`
